Excel Data Cleaning Project

Cleaned and formatted a product dataset using **Microsoft Excel**.

Tasks Completed

* Handled missing **Price** and **Category** values.
* Corrected **Product Name** inconsistencies and **Category** typos.
* Removed duplicate rows.
* Split **Product ID** into **Manufacturing Date** and **Country Code**.
* Merged **Brand Name** and **Product Name**.
* Applied **Currency** and **DD-MM-YYYY** date formatting.
* Applied **Conditional Formatting** to Price and Electronics categories.

Tools

**Microsoft Excel | Formulas | Find & Replace | Data Cleaning | Conditional Formatting**
